## 2. Component Specifications

### ESP32 DevKit V1
- Main microcontroller.
- Built-in Wi-Fi connectivity.
- I2C communication.
- Processes sensor readings.

### INA226
- Measures battery bus voltage.
- Measures current through an external shunt.
- Communicates using I2C.

### DS18B20
- Digital temperature sensor.
- One-Wire communication.
- Used for battery surface temperature monitoring.

### OLED SSD1306
- 0.96-inch display.
- I2C interface.
- Displays voltage, current and temperature.

### LM2596
- DC-DC buck converter.
- Converts battery voltage to regulated 5V.
- Supplies power to ESP32.

## 3. Battery Specifications

- Nominal voltage: 12V
- Rated capacity: 7Ah
- Battery type: Sealed lead-acid (assumed)
- Application: Educational battery monitoring prototype.
